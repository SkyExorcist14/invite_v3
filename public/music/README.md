# Background music

Place ONE legally-owned or properly licensed audio file here, named exactly:

    wedding-song.mp3

The site will never autoplay it with sound on page load — that's blocked by
every modern mobile browser anyway. Instead, the very first tap that opens
the invitation card is used as the "user gesture" moment to attempt playback.
If that's blocked too, guests can simply tap the music button in the
bottom-right corner once the site is open.

If this file is missing, the music button hides itself automatically and
nothing breaks.

Do NOT download songs from Spotify, YouTube, or any streaming service — that
violates copyright. Use a track you own, a royalty-free track, or one
licensed for this use.
