Drop your caricature images into THIS folder (public/images/) using
these EXACT names:

      haldi.png          → Haldi & Mehendi card
      sangeet.png        → Sangeet card
      anand-karaj.png    → Anand Karaj card
      reception.png      → Reception card

TIPS
• PNG with a transparent background looks best (the couple "floats"
  on the colored banner). JPG works too but will show a rectangle.
• Roughly square or portrait images work best. Aim for ~800px tall.
• If a file is missing, that card automatically shows a built-in
  illustrated couple instead — nothing breaks.

WHERE TO GET THEM
• Use the Ghibli/painterly couple caricatures you have.
• Or search Pinterest for "indian wedding couple caricature png".
• Or commission one — many Etsy/Fiverr artists do these.

To change a filename, edit the matching `imagePath` line in
src/data/weddingData.ts.
